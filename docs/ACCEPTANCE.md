# 실환경 검증 기록표 — 0.1.3 / 2026-09-15

아래 파일/HKCU 통과 기록은 0.1.2에서 수행한 것입니다. 0.1.3의 재시작 복구·프로필 저장은 별도 회귀 검사로 확인하며, 실제 정책을 완화했다가 복원하는 시스템 시험은 수행하지 않습니다.

Sandboxie Plus 설치와 전용 설정 적용은 각 사용자 확인 후 진행했습니다. 계정 없는 시험은 별도의 무해한 시험 토큰만 사용했습니다. 시험 파일·레지스트리·box 데이터는 삭제하지 않았습니다.

파일·레지스트리의 계정 없는 격리와 재실행 유지 시험은 통과했지만, WebCache COM/IPC와 같은 이름의 호스트 프로세스 보호 시험은 남아 있습니다. 공식 카카오톡을 box 안에서 실행하거나 계정 인증을 진행하지 않았습니다. 아래 B 항목은 모두 사용자 확인이 필요한 미검증 항목입니다. 프로세스 존재나 명령 종료를 로그인 성공으로 기록하지 않습니다.

기록에는 날짜, Windows 빌드, SIDETALK 버전, Sandboxie 버전, 공식 앱 버전, 전용 box, 관찰 결과만 사용합니다. 계정 ID·대화 내용·인증 정보·사용자 SID·소유 토큰·실행 식별자는 기록하지 않습니다.

최초 probe 시도는 Roaming known-folder 조회가 빈 값을 반환해 실행 전 단계에서 중단됐습니다. 정확한 호스트 논리 경로 검증은 유지한 채 DoNotVerify 방식으로 경로를 조회하도록 수정했고, 이후 시험을 완료했습니다. 이 과정에서 보안 기능을 낮추거나 호스트 예외를 추가하지 않았습니다.

실제 근거 파일은 다음과 같습니다.

- artifacts/verification/native-config-after-setup.json
- artifacts/verification/native-config-after-recovery.json
- artifacts/verification/isolation-probe/host-between-runs.json
- artifacts/verification/isolation-probe/host-after-recheck.json
- artifacts/verification/isolation-probe/manifest.json

시험 산출물에는 무해한 시험 토큰과 실행 식별자가 포함되므로 저장소에는 추적하지 않습니다. SIDETALK는 이 데이터를 자동 삭제하지 않습니다.

## B. 공식 카카오톡 검사 — 남은 A 항목 완료 + 별도 실계정 실행 확인 후

| 검사 | 절차 | 통과 기준 | 상태 |
|---|---|---|---|
| 별도 시작 화면 | 메인 실행 상태에서 SIDETALK 전용 box로 공식 카카오톡을 시작 | 로그인 전 메인 계정 프로필·계정·대화가 자동 노출되지 않음 | 미검증 |
| 보조 로그인·기기 인증 | 사용자가 공식 보조 카카오톡 창에서 직접 진행 | 의도한 보조 계정의 인증 완료를 사용자가 확인 | 미검증 |
| 동시 로그인 | 메인과 보조 창의 계정 표시를 사용자가 비교 | 서로 다른 두 계정이 동시에 유지되고 메인이 로그아웃되지 않음 | 미검증 |
| 송신 | 사용자가 동의한 시험 대화에서 각 계정으로 전송 | 각 계정의 메시지가 올바른 상대에게 도착 | 미검증 |
| 수신 | 두 계정 각각으로 시험 메시지를 수신 | 올바른 창과 계정에 표시 | 미검증 |
| 알림 | 두 창을 최소화하고 각 계정에 수신 | 계정별 알림·소리·읽음 동작을 사용자가 확인 | 미검증 |
| 보조 자체 종료·재실행 | 보조 카카오톡에서 정상 종료 후 같은 box로 재실행 | 보조 설정과 로컬 데이터가 유지됨. 인증 유지는 공식 앱 정책에 따름 | 미검증 |
| 전용 box 종료 | 미저장 작업을 정리한 뒤 SIDETALK의 전용 종료를 사용 | 지정된 전용 box만 종료되고 데이터가 삭제되지 않음 | 미검증 |
| 메인 무간섭 | 보조 실행 전후 메인 창·계정·송수신 상태를 사용자가 확인 | 메인 프로세스·로그인·대화가 유지되고 SIDETALK가 메인 데이터를 쓰지 않음 | 미검증 |

보조 카카오톡 실행 단계에서는 SIDETALK가 인증·대화 데이터를 복사하거나 공유하지 않습니다. 기기 인증과 로그인은 사용자가 공식 카카오톡 창에서 직접 수행해야 합니다.

## 중단 기준

다음 중 하나라도 발생하면 로그인·메시지 단계로 넘어가지 않습니다.

- 메인 데이터, 인증 정보, 계정 화면이 보조 환경에서 노출됨
- 메인 카카오톡 또는 다른 box의 프로세스가 종료·변경됨
- 프로세스의 box 이름·사용자 SID·native 격리 경로를 확인할 수 없음
- 호스트 파일·레지스트리 원본이 변경되거나 box 데이터가 호스트에 나타남
- 서명·버전·서비스·드라이버·설정 출처가 검증되지 않음
- 자동 삭제, 패치, 후킹, 핸들 강제 해제, 인증 우회, 보안 기능 해제가 필요하다는 오류가 발생함

중단 시 오류 메시지와 검토에 필요한 진단만 기록하고, 공유 전 사용자 경로·프로세스 정보를 확인합니다. 원인을 해결하기 위해 광역 종료나 메인 데이터 변경을 사용하지 않습니다.
