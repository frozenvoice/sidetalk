# 실환경 검증 기록표

**아래 항목은 아직 수행하지 않았습니다.** Sandboxie 설치/설정 변경 및 실제 계정 사용은 각각 사용자의 확인이 필요합니다. 실패하면 로그인·메시지 단계로 넘어가지 않습니다. 프로세스 존재는 로그인 성공이 아닙니다.

기록: 날짜 / Windows 빌드 / SIDETALK 버전 / Sandboxie Plus와 Start.exe·SbieDll.dll 버전 / 메인·보조 KakaoTalk 도움말 버전 / 전용 box 이름 / 관찰자. 계정 ID·대화 내용·인증 정보는 기록하지 않습니다.

## A. 계정을 쓰지 않는 격리 사전 검사 — 사용자 승인 후

샌드박스에 시험 프로그램을 실행하는 단계도 설정 적용 후 진행합니다. 실제 카카오 인증·대화 파일을 열어 비교하지 말고, 별도의 무해한 sentinel(시험 문자열)을 사용하세요.

| 검사 | 방법 | 통과 근거 | 상태 |
|---|---|---|---|
| 깨끗한 전용 환경 | 새 box의 출처와 SIDETALK 소유 표식 확인. 이전 Kakao 데이터가 없는 신규 환경인지 확인 | 기존 box 재사용/메인 데이터 복사 없음 | 미검증 |
| 호스트 파일 숨김 | 현재 프로필·Roaming·Local·ProgramData/Kakao 보호 위치에 승인된 별도 시험 파일을 만든 뒤 동일 전용 box의 무해한 시험 프로그램으로 읽기 시도 | 호스트 시험 문자열을 읽을 수 없음 | 미검증 |
| 호스트 레지스트리 숨김 | HKCU의 SIDETALK 시험 키에 임의 값을 두고 box 안에서 조회. 실제 Kakao 키 열람 금지 | 호스트 시험 값이 보이지 않음 | 미검증 |
| 호스트 WebCache 경유 차단 | 정책 2 ClosedClsid·ClosedIpcPath가 적용된 전용 box에서 무해한 COM/IPC 연결 시험. 실제 브라우저·Kakao 캐시 조회 금지 | 지정한 호스트 WebCache 클래스/IPC에 연결 불가. 호환성 실패 시 예외를 열지 않고 보고 | 미검증 |
| 쓰기 분리 | box 안에서 같은 가상 경로·시험 키에 다른 문자열 작성 | 호스트 원본 값은 그대로, 보조 값은 전용 저장소에만 존재 | 미검증 |
| 영속성 | 시험 프로그램 종료 후 동일 box 재실행 | 보조 시험 값 유지 | 미검증 |
| 메인 프로세스 무간섭 | 같은 이름의 무해한 호스트 시험 프로그램을 함께 실행하고 전용 box 종료 | 호스트 시험 프로세스 유지 | 미검증 |
| 다른 box 무간섭 | 별도의 시험 box 사용은 추가 승인 필요. 기존 업무 box를 시험에 사용하지 않음 | 다른 box의 프로세스·파일·설정 유지 | 미검증 |
| 설정 변경 감지 | 전용 box만 대상으로 승인된 안전한 테스트 드리프트를 넣고 새로고침 | 명확한 사유로 실행 차단. 전역 설정 변경 없음 | 미검증 |

SIDETALK는 시험 파일/키를 자동 생성하거나 삭제하지 않습니다. 시험 위치와 변경 내용을 검토하고 승인한 다음 진행합니다. 생성된 보조 환경 데이터는 검사 후에도 자동 삭제하지 않습니다.

## B. 공식 카카오톡 검사 — A 통과 + 실계정 사용 승인 후

| 검사 | 절차 | 통과 기준 | 상태 |
|---|---|---|---|
| 별도 시작 화면 | 메인 실행 중 보조 실행. 로그인 전 보조 화면 확인 | 메인 프로필·계정·대화 자동 노출 없음 | 미검증 |
| 보조 로그인·기기 인증 | 사용자가 공식 보조 카카오톡 창에서 직접 진행 | 의도한 보조 계정 로그인 확인 | 미검증 |
| 동시 로그인 | 양쪽 창의 계정 표시를 사용자가 비교 | 서로 다른 두 계정 동시 사용, 메인 로그아웃 없음 | 미검증 |
| 송신 | 사용자가 동의한 시험 대화에서 두 계정 각각 전송 | 각 계정에서 보낸 내용이 올바른 상대에게 도착 | 미검증 |
| 수신 | 두 계정 각각으로 시험 메시지 수신 | 올바른 창/계정에 표시 | 미검증 |
| 알림 | 두 창을 최소화하고 각 계정에 수신 | 계정별 알림·소리·읽음 동작을 사용자 확인 | 미검증 |
| 종료·재실행 | 보조 자체 종료, SIDETALK 재실행, 보조 재실행 | 의도한 보조 설정/로컬 데이터 유지. 인증 유지는 공식 앱 정책에 따름 | 미검증 |
| 전용 종료 | 미저장 작업 정리 후 SIDETALK 전용 종료 | 해당 box만 종료, 데이터 삭제 없음 | 미검증 |
| 메인 무간섭 | 전후 메인 PID/세션, 로그인, 송수신 확인 | 메인 프로세스·로그인 유지, SIDETALK의 메인 설치/데이터 쓰기 없음 | 미검증 |
| 업데이트 | 버전 변경 후 A/B 재검증 | 새 버전에서 동일 기준 만족 | 미검증 |

메인 앱은 정상 실행 중 자체적으로 데이터를 기록하므로 단순한 파일 수정 시간 변화를 SIDETALK의 간섭으로 단정하지 않습니다. 필요하면 사용자가 승인한 관찰 도구로 SIDETALK/Sandboxie의 실제 쓰기 주체를 구분합니다.

## 중단 기준

메인 데이터 노출, 메인 로그아웃/종료, 샌드박스 이탈, 서명 불명, 제어 경로 불명, 보안 기능 해제가 필요하다는 오류가 발견되면 중단합니다. 패치·후킹·핸들 해제·인증 우회·광역 종료로 해결하지 않습니다. 오류 메시지와 개인정보 없는 진단으로 원인과 가능한 범위를 보고합니다.
