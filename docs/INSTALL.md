# 설치 · 업데이트 · 제거

SIDETALK는 Windows 사용자별 설치 프로그램 **`SIDETALK-Setup.exe`** 로 설치합니다. 관리자 권한이 필요 없고, Git 저장소나 `artifacts` 폴더를 열 필요도 없습니다.

## 설치하고 실행하기

1. `SIDETALK-Setup.exe`를 실행하고 안내에 따라 설치합니다. 바탕 화면 바로가기는 선택 사항이며 기본값은 꺼짐입니다.
2. 마지막 화면의 **SIDETALK 실행**을 선택하거나, Windows 키를 누르고 `sidetalk`을 입력해 **SIDETALK**를 엽니다.

| 항목 | 위치 |
|---|---|
| 프로그램 파일 | `%LOCALAPPDATA%\Programs\SIDETALK` (고정, 다른 위치는 지원하지 않음) |
| 시작 메뉴 | `%APPDATA%\Microsoft\Windows\Start Menu\Programs\SIDETALK.lnk` (설치 프로그램 소유) |
| 바탕 화면(선택) | `SIDETALK.lnk` (설치 프로그램 소유) |
| 설치된 앱 | 설정 → 앱 → 설치된 앱 → **SIDETALK** (현재 사용자 등록) |
| 사용자 데이터 | `%LOCALAPPDATA%\SIDETALK` (설치 위치와 별개) |

시작 메뉴 항목은 바로 만들어지지만 Windows 검색 색인에 반영되기까지 잠시 걸릴 수 있습니다. 검색 결과에 없으면 시작 메뉴의 전체 앱 목록에서 **SIDETALK**를 여세요. 설치 프로그램은 검색 색인이나 레지스트리를 별도로 조작하지 않습니다.

**설치 성공은 실행 준비가 아닙니다.** SIDETALK는 열릴 때마다 공식 카카오톡·Sandboxie Plus 1.18.4·전용 환경을 다시 검사하며, 준비가 되지 않았으면 이유를 표시하고 실행을 막습니다. 공식 카카오톡과 Sandboxie는 설치 프로그램에 포함되지 않으므로 사용자가 별도로 설치합니다.

## 업데이트

새 `SIDETALK-Setup.exe`를 실행하면 같은 설치(같은 AppId·위치)를 업데이트합니다. 프로그램 파일만 교체하고 Installed Apps의 버전을 갱신합니다. 같은 버전 재설치는 허용하고, 설치된 버전보다 낮은 버전으로의 변경은 파일을 복사하기 전에 거부합니다.

설치·업데이트·제거 전에는 **SIDETALK 창과 IsolationProbe를 정상 종료**하세요. 실행 중이면 설치 프로그램이 이유를 보여 주고 아무것도 바꾸지 않은 채 멈춥니다. 설치 프로그램은 어떤 프로세스도 종료하지 않으며, 카카오톡과 Sandboxie(Start.exe·SandMan·SbieCtrl·서비스·드라이버)는 닫을 필요가 없습니다. 이름만 같은 다른 프로그램을 검사하거나 종료하지 않고, 설치 위치의 SIDETALK 파일이 사용 중인지만 확인합니다.

## 사용자 데이터

설치·업데이트·제거는 `%LOCALAPPDATA%\SIDETALK`를 이동·초기화·삭제하지 않습니다. 프로필(`profile.json`), Sandboxie 전용 환경과 보조 계정 데이터(`Boxes`), 명령·복구 기록, 빠른 실행 동의, 바로가기 선택, 보조 창 식별 설정이 그대로 남습니다. 설치 위치가 바뀌었다는 이유로 새 전용 환경이나 소유 식별자를 만들지 않습니다. 제거 후 다시 설치하면 같은 프로필과 전용 환경을 그대로 사용합니다. 데이터까지 지우려면 SIDETALK 사용을 마친 뒤 사용자가 직접 판단해 정리해야 합니다.

## "보조 카카오톡 실행" 바로가기

앱의 **실행 · 식별** 탭에서 만드는 **보조 카카오톡 실행** 바로가기와 로그인 시 실행 항목은 설치 프로그램의 **SIDETALK** 바로가기와 별개입니다. 앱이 소유 표식·해시로 관리합니다.

- **설치 위치가 바뀐 경우**(예: 예전 `artifacts\publish\win-x64\Sidetalk.exe`): 앱이 이전 실행 파일 경로를 알려 줍니다. **바로가기 선택 저장**을 누르면 소유가 확인된 바로가기만 새 설치 위치로 갱신합니다. 사용자가 바꾼 바로가기, 같은 이름의 다른 바로가기, 손상되거나 미완료인 설정은 그대로 두고 이유를 표시합니다. 자동으로 고치거나 삭제하지 않습니다.
- **빠른 실행 동의**는 프로필·카카오톡/Sandboxie 설치·격리 설정 범위에 묶여 있고 SIDETALK 실행 파일 위치를 포함하지 않습니다. 설치 위치 이동으로 동의 범위가 넓어지거나 새로 생기지 않으며, 그 범위가 바뀌면 기존처럼 다시 확인합니다.
- **제거할 때**: 제거 프로그램이 파일을 지우기 전에 `Sidetalk.exe --uninstall-owned-integration`을 실행합니다. 이 설치의 `Sidetalk.exe`를 실행하는 **소유가 확인된** 바로가기만 삭제해 깨진 바로가기가 남지 않게 합니다. 사용자가 바꾼 바로가기나 다른 위치의 SIDETALK를 실행하는 바로가기는 남기고 안내합니다. 저장된 선택·동의·기록은 지우지 않으므로, 다시 설치한 뒤 **바로가기 선택 저장**으로 다시 만들 수 있습니다. 정리에 실패해도 다른 것을 지우는 대체 동작은 없습니다.

## 서명과 SmartScreen

현재 개발 빌드의 `SIDETALK-Setup.exe`는 코드 서명되지 않았으며, 함께 생성되는 `SIDETALK-Setup.exe.unsigned.txt`가 이를 표시합니다. Windows SmartScreen이 실행 전에 경고할 수 있습니다. 받은 파일은 `SIDETALK-Setup.exe.sha256`의 값과 비교하세요. 실제 인증서가 준비되면 `scripts/build-installer.ps1 -SignToolPath <signtool.exe> -CertificateThumbprint <SHA-1> [-TimestampUrl <URL>]`로 서명하고, 빌드가 서명자를 검증합니다. 서명되지 않은 빌드는 서명된 것처럼 표시하지 않습니다.

## 소스에서 설치하기(개발자)

저장소 루트의 `build-local.cmd`가 검증·publish·`SIDETALK-Setup.exe` 생성·설치 실행까지 한 번에 진행합니다. 자세한 옵션은 [루트에서 로컬 빌드·설치](LOCAL-RUN.md)를 참고하세요.
