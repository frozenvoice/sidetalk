# SIDETALK design

The user's tidy Korean Windows utility brief is the visual authority. Native operation comes first: standard window chrome, keyboard access, meaningful disabled states, no animations or invented metrics.

## Surface

One compact desktop window, light warm-gray canvas, white working surface, dark ink, muted teal action accent. A quiet SIDETALK wordmark and Korean description lead directly to the observed secondary process state. Primary launch and stop sit together. Below, prerequisites are aligned rows; setup and diagnostics live in a separate tab. The bottom sentence distinguishes process state from user-confirmed login.

## Tokens

Malgun Gothic / Segoe UI; 14 px body, 26 px status title. Spacing 8/12/16/24/32. Ink #202C2A; secondary #53625E; accent #21685B; background #F3F5F2; divider #D8DFD9. Status text carries meaning independently of color. Native focus cues and scrollable minimum-size layouts are mandatory.

## States

Checking, missing Sandboxie, setup required, configuration blocked, ready, processes running, query failure. Never display logged in based on process count. Setup exports a reviewable file only. System configuration stays under the user's control. Closing SIDETALK does not terminate KakaoTalk.
